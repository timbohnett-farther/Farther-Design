# Farther image bank

196 brand-approved photographs exported from the Figma file **"2026 Image Bank"**
(page: Image-Library). Each image exists in two sizes:

- `library/<slug>.jpg` — web-ready, max edge 2400px, JPEG q82. Use these in designs.
- `thumbs/<slug>.jpg` — 360px-wide thumbnails for pickers/contact sheets.
- `manifest.json` — machine-readable index: `{ slug, category, w, h, outW, outH }`
  (`w`/`h` = original Figma pixels, `outW`/`outH` = the library file's pixels).

Browse visually: open `../../image-library.html` (filter by category, click to copy a path).

## How to choose imagery (brand rules)

- Warm, natural light; never corporate stock-feeling. Aspirational but believable.
- Full-bleed behind hero moments and section covers; pair with the frosted-glass
  surface or a Charcoal protection layer for text.
- Abstract/light imagery suits dark "signal" slides; landscapes suit calm section
  breaks; people imagery carries marketing pages and client stories.
- A few files are watermarked comps kept for layout parity only — do NOT ship them:
  `stocksy-comp-watermarked-*`, `shutterstock-1937758900`, `shutterstock-offset-*`,
  `adobestock-547151154-preview`.
