Performance calculation methodology

Constant-weight approach. Model returns use the industry-standard constant-weight methodology: target allocation weights from each rebalance date, assumed monthly/quarterly rebalancing to exact target weights, reinvestment of all dividends and distributions, and underlying ETF expense ratios. Does not account for drift between rebalances, nor reflect advisory fees, transaction costs, or taxes.

[1] Gross vs. Net performance. Gross returns reflect reinvested dividends and underlying ETF expense ratios before advisory fees. Net returns deduct the strategy's stated management fee using a linear pro-rata approximation: for periods < 1 year, Net = Gross − (months ÷ 12) × Annual Fee. For annualized multi-year periods, Net Annualized = Gross Annualized − Annual Fee. Important: this methodology is an approximation; actual client net returns will differ based on specific fee schedules, account size, timing of fee deductions, and any additional fees charged at the account level (custodial, transaction, wrap). Investors should request account-level performance reports for their actual net-of-fee experience. Future periods will use actual fee deductions consistent with GIPS 2020 §1.A.39.

Period availability. Performance is only shown for periods with complete data since inception. Multi-year periods (3Y, 5Y, 10Y) appear only when fully elapsed. Annualized: (1 + Total Return)^(1/years) − 1. Sub-1-year periods are not annualized.

Benchmark. Calculated using a buy-and-hold approach (no rebalancing) for periods of one year or less, and annual rebalancing for multi-year periods. This methodology differs from the model portfolio approach and ensures benchmark returns are transparent and verifiable using publicly available ETF data.

Definitions

[2] Global equity beta. Measure of portfolio return volatility relative to the iShares MSCI ACWI ETF (ACWI), calculated using 36 months of weekly returns (or available history where shorter). 1.0 = moves in line with ACWI; >1.0 = more volatile; <1.0 = less volatile. Source: FinMason. Hypothetical — see note [3] below.

[3] Historical return (1Y). Hypothetical total return over the trailing 1-year period, applying current model weights to historical security returns. Includes price appreciation and reinvested dividends. Sourced from FinMason.

[4] Historical volatility (1Y). Hypothetical annualized volatility applying current model weights to historical security volatilities over a 1-year period. Sourced from FinMason.

[5] Historical Sharpe ratio (1Y). Hypothetical risk-adjusted return — trailing 1-year return ÷ trailing 1-year volatility — using current model weights. Higher = better risk-adjusted performance. Sourced from FinMason.

[6] Current yield. Portfolio-weighted annual income (interest or dividends) ÷ current market price, gross of advisory fees and account-level expenses. Sourced from FinMason.

Performance calculations and portfolio metrics are based on information from FinMason and internal calculations. All data is believed to be accurate but has not been audited. All metrics and holdings are presented as of the period-end date shown.
